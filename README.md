# 과제 링크 제출함

학생들에게서 과제 링크(구글 문서, 깃허브, 노션, 유튜브, 직접 만든 웹페이지 등)를 모으는 작은 웹 서비스입니다.
따로 설치할 패키지 없이 Node.js만 있으면 실행됩니다.

## 할 수 있는 일

**학생**

- 선생님이 보내 준 주소를 열어 학번·이름·링크를 제출하고 접수증을 받습니다. 회원 가입이나 로그인은 없습니다.
- 제출할 때 정한 비밀번호로 나중에 링크를 고치거나 제출 내용을 다시 확인합니다.
- `localhost` 주소처럼 다른 사람이 열 수 없는 링크는 제출 단계에서 걸러 줍니다.

**선생님** (`/admin`)

- 과제를 만들고 마감 일시와 지각 제출 허용 여부를 정합니다. 과제마다 학생에게 보낼 주소가 생깁니다.
- 제출 현황을 표로 보고, 학번·이름으로 찾고, CSV(엑셀)로 내려받습니다.
- 학생 명단을 등록하면 과제마다 미제출자를 볼 수 있고, 명단에 없는 학번의 제출을 막을 수도 있습니다.
- 학생이 링크를 바꾸면 이전 링크가 기록으로 남습니다. 마감 뒤에 링크를 바꾼 제출은 "지각"으로 표시됩니다. (이름이나 메모만 고친 것은 지각으로 치지 않습니다.)
- 비밀번호를 잊은 학생은 비밀번호만 초기화해 줄 수 있습니다.

## 시작하기

1. [Node.js](https://nodejs.org) 22.13 이상을 설치합니다. (LTS 버전이면 됩니다.)
2. 이 저장소를 내려받아(GitHub 화면의 **Code** 버튼 → **Download ZIP**) 압축을 풀고, 그 폴더에서 서버를 실행합니다. Windows에서는 `start.bat`을 두 번 눌러도 됩니다.

   ```bash
   node server.js
   ```

3. 실행 창에 주소와 **관리자 비밀번호**가 표시됩니다. 비밀번호는 처음 한 번만 보여 주니 적어 두세요.
4. 브라우저에서 `http://localhost:3000/admin` 을 열어 로그인합니다.
5. **설정**에서 비밀번호를 바꾸고, 사이트 이름과 학생 명단을 넣습니다.
6. **과제 → 새 과제**로 과제를 만들고 "학생에게 보낼 주소"를 복사해 학생들에게 전합니다.
   관리 화면을 `localhost`로 열었다면 주소의 `localhost` 부분을 학생이 접속할 수 있는 주소로 바꿔야 합니다. (아래 참고)

관리자 비밀번호를 잊었다면 아래 명령으로 새로 만듭니다.

```bash
node server.js --reset-admin-password
```

## 학생들이 접속할 수 있게 하기

`localhost` 주소는 서버를 켠 컴퓨터에서만 열립니다. 상황에 맞는 방법을 고르세요.

### 1. 같은 네트워크에서 쓰기 (교실, 실습실)

실행 창의 "같은 네트워크" 주소(예: `http://192.168.0.12:3000`)를 학생들에게 알려 줍니다.
컴퓨터의 방화벽이 물어보면 접속을 허용해야 하고, 서버를 켠 컴퓨터가 켜져 있는 동안만 쓸 수 있습니다.
학교 무선망이 기기끼리의 접속을 막아 둔 경우에는 이 방법을 쓸 수 없습니다.

### 2. 내 컴퓨터를 잠시 인터넷에 공개하기

터널 프로그램을 쓰면 내 컴퓨터의 서버에 인터넷 주소를 붙일 수 있습니다.
예를 들어 Cloudflare가 배포하는 `cloudflared`를 설치한 뒤, 서버를 켜 둔 채로 다른 창에서 다음처럼 실행하면 `https://….trycloudflare.com` 주소가 나옵니다.

```bash
HOST=127.0.0.1 TRUST_PROXY=1 node server.js
```

```bash
cloudflared tunnel --url http://localhost:3000
```

`HOST=127.0.0.1`은 터널을 거친 접속만 받고 같은 네트워크에서 직접 들어오는 접속은 받지 않게 합니다. `TRUST_PROXY=1`과 함께 쓸 때는 꼭 넣어 주세요.
Windows 명령 프롬프트에서는 `set HOST=127.0.0.1` 과 `set TRUST_PROXY=1` 을 차례로 실행한 다음 `node server.js` 를 실행합니다.
이 주소는 실행할 때마다 바뀌고 컴퓨터를 끄면 닫히므로, 수업 시간 안에 걷는 과제에 알맞습니다.

### 3. 항상 켜 두기 (서버, 클라우드)

며칠에 걸쳐 받으려면 항상 켜져 있는 곳에 올립니다. `Dockerfile`이 들어 있습니다.

```bash
docker build -t assignment-links .
```

```bash
docker run -d --name assignment-links --restart unless-stopped \
  -p 3000:3000 \
  -v assignment-links-data:/data \
  -e ADMIN_PASSWORD='길고-추측하기-어려운-비밀번호' \
  assignment-links
```

올릴 곳을 고를 때 꼭 확인할 점이 두 가지 있습니다.

- **데이터가 남는 저장 공간.** 제출 내용은 `/data` 폴더의 파일 하나에 저장됩니다. 다시 배포하거나 재시작할 때 디스크가 초기화되는 호스팅에서는 제출이 모두 사라지므로, 반드시 볼륨(영구 디스크)을 `/data`에 연결하세요.
- **HTTPS.** 이 서버는 HTTP로만 응답합니다. 인터넷에 공개할 때는 HTTPS를 붙여 주는 호스팅이나 리버스 프록시(Caddy, nginx 등) 뒤에 두고, `TRUST_PROXY=1`을 함께 설정하세요.
  프록시가 같은 서버에 있다면 위 명령의 `-p 3000:3000`을 `-p 127.0.0.1:3000:3000`으로 바꿔서, 프록시를 거치지 않고는 접속할 수 없게 하세요.

## 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 접속 포트 |
| `HOST` | 모든 주소 | 특정 주소로만 받으려면 지정합니다. 예: `127.0.0.1` |
| `DATA_DIR` | `data` | 데이터를 저장할 폴더. 상대 경로는 이 프로그램 폴더를 기준으로 합니다. |
| `ADMIN_PASSWORD` | 없음 | 관리자 비밀번호(8자 이상). 정하면 관리 화면에서는 바꿀 수 없습니다. 정하지 않으면 처음 실행할 때 자동으로 만들어 실행 창에 보여 줍니다. |
| `TRUST_PROXY` | `0` | 서버 앞에 있는 프록시의 개수. 프록시나 터널 뒤에서는 `1`로 두어야 접속자별 요청 제한이 제대로 동작합니다. 프록시 없이 직접 받는 서버에서는 `0`으로 두세요. 프록시가 알려 주는 접속자 주소(`X-Forwarded-For`)는 같은 컴퓨터나 사설망에서 들어온 접속일 때만 믿습니다. |

## 데이터와 백업

- 모든 데이터는 `data/submissions.db`(SQLite) 파일 하나에 들어 있습니다.
- 백업하려면 서버를 멈춘 뒤 이 파일을 복사해 두세요. 과제별 CSV를 내려받아 두는 것도 방법입니다.
- 과제를 삭제하면 그 과제의 제출과 이전 제출 기록도 함께 지워집니다.

## 알아 둘 점

- 학생이 정한 비밀번호는 암호화된 형태(scrypt 해시)로만 저장되어 선생님도 볼 수 없습니다. 잊어버린 학생은 관리 화면의 **자세히 → 비밀번호 초기화**로 풀어 줍니다.
- 로그인이 없으므로 학번을 아는 다른 사람이 먼저 제출해 버릴 수 있습니다. 이 경우 본인은 "이미 제출된 학번"이라는 안내를 받게 되고, 선생님이 그 제출을 삭제하면 다시 낼 수 있습니다. 설정의 **명단에 있는 학번만 제출 받기**를 켜면 명단에 없는 학번으로는 낼 수 없습니다.
- 비밀번호를 8번 틀리면 그 학번은 10분 동안 잠깁니다. 관리자 로그인은 10번 틀리면 10분 동안 잠깁니다. 선생님이 제출을 삭제하거나 비밀번호를 초기화하면 그 학번의 잠금도 풀립니다.
- 한 학생이 링크를 바꿀 수 있는 횟수는 30번, 과제 하나가 받는 제출은 5,000건까지입니다. 장난으로 제출을 끝없이 쌓는 것을 막기 위한 한도입니다. 엉뚱한 학번의 제출이 쌓인다면 **명단에 있는 학번만 제출 받기**를 켜세요.
- 관리자 로그인은 7일 동안 유지됩니다. 함께 쓰는 컴퓨터에서는 로그아웃하세요. 다른 기기에 남은 로그인은 **설정 → 다른 기기에서 로그아웃**으로 끊을 수 있고, 로그인한 기기를 잃어버렸다면 서버에서 아래 명령을 실행하세요. `ADMIN_PASSWORD`를 바꾸고 서버를 다시 시작해도 예전 로그인이 모두 끊깁니다.

  ```bash
  node server.js --logout-all
  ```

- 서버 프로그램은 한 개만 실행하세요. 요청 제한을 메모리에 기록하기 때문에 여러 개를 동시에 띄우는 구성은 지원하지 않습니다.
- 학번과 이름은 개인정보입니다. 학기가 끝나면 CSV로 내려받은 뒤 과제를 삭제하는 것을 권합니다.

## 개발

```bash
npm test
```

Node.js 내장 테스트 러너로 서버 동작(제출, 마감, 비밀번호, 명단, 관리자 인증, 요청 위조 차단, 보안 헤더 등)을 검사합니다.

```
server.js          실행 파일
src/app.js         HTTP 서버: 주소별 처리, 인증, 요청 제한
src/db.js          SQLite 저장소와 스키마
src/security.js    비밀번호 해시, 토큰, 요청 제한기
src/main.js        환경 변수 읽기와 시작·종료
shared/rules.js    입력 검사 규칙 (서버와 브라우저가 함께 사용)
shared/csv.js      CSV 만들기
public/            학생 화면(index.html, student.js)과 관리 화면(admin.html, admin.js)
test/              자동 테스트
```
